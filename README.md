## Главные изменения относительно исходной идеи

- Один точный товар и единый предел полной цены на группу.
- Возвратный платеж участия без штрафа за отказ до оплаты товара.
- Для MVP платеж участия возвращается отдельно; покупатель оплачивает поставщику полную цену. Временная потребность в деньгах раскрывается заранее.
- Поставщик заранее фиксирует минимальный оплаченный объем и сохраняет цену после выпуска партии независимо от дальнейших индивидуальных отмен.
- Закрытый сбор предложений и финальный раунд с объективным выбором победителя.
- Возвраты, частичное исполнение и комиссия учитываются отдельно по каждому заказу.
- Проверяется прибыльная завершенная закупка, а не только количество депозитов.

Параметры 20/25 участников, минимум 16, 200 000 сум и комиссия 3% — предложенные настройки пилота. Рыночные цены и экономика поставщиков еще требуют практической проверки. Документы описывают решение для реализации; договорная и платежная схема должны пройти обозначенные проверки до приема реальных денег.

## Mini App и бот — первая исполняемая версия

Рабочее название: **Birga**. Python 3.9+, SQLite, HTML/CSS/JavaScript; установка пакетов не требуется.

```bash
python3 -m app.server
```

Открыть [локальное приложение](http://127.0.0.1:8080).

[Инструкция запуска, сценарий демонстрации и подключение Telegram](docs/04-running-the-app.md).

```bash
python3 -m unittest discover -s tests -v
```

Демо содержит тестовые группы и симулятор платежей. Настоящий бот запускается после настройки BOT_TOKEN и публичного HTTPS-адреса в локальном `.env`. Реальные платежные интеграции и production-размещение пока не реализованы.
